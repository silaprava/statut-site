# Сайт юридичної фірми «Статут»

Готовий статичний сайт (HTML/CSS/JS) — без бекенду, без витрат на хостинг.

## Структура

```
index.html      — Головна
about.html      — Про нас
services.html   — Послуги
contacts.html   — Контакти
css/style.css   — усі стилі
js/script.js    — мобільне меню + форма
```

## Що обов'язково змінити перед публікацією

1. **Назва фірми, телефон, email, адреса** — зараз стоять приклади (`СТАТУТ`, `+380 44 000 00 00`, `info@statut-law.ua`, вул. Хрещатик 1). Заміни в усіх 4 файлах (пошук по слову легко зробити в будь-якому редакторі).
2. **Карта на contacts.html** — зараз вбудована OpenStreetMap-карта з довільними координатами Києва. Онови координати `bbox` та `marker` на реальну адресу офісу (можна взяти на openstreetmap.org: знайти адресу → "Share" → "Embed").
3. **Форма зворотного зв'язку** — зараз вона нічого нікуди не надсилає (лише показує "Дякуємо"). Щоб листи реально приходили на пошту, безкоштовно підключи один із сервісів:
   - **Formspree** (formspree.io) — безкоштовний план, 50 повідомлень/міс.
   - **Getform** (getform.io) — теж є безкоштовний план.
   Просто додаєш `action="https://formspree.io/f/ТВІЙ_ID"` до тега `<form>` в contacts.html — і форма запрацює без бекенду.

## Як розмістити безкоштовно (кроки)

### Варіант A — GitHub Pages (найпростіший)

1. Зареєструйся на github.com (безкоштовно).
2. Створи новий репозиторій, наприклад `statut-site`.
3. Завантаж туди всі файли з цієї папки (кнопка "Add file" → "Upload files").
4. Перейди в Settings → Pages → у "Branch" вибери `main` → Save.
5. Через хвилину сайт буде доступний за адресою на кшталт:
   `https://твій-логін.github.io/statut-site/`

### Варіант B — Cloudflare Pages (швидший, є свій домен *.pages.dev)

1. Зареєструйся на pages.cloudflare.com.
2. "Create a project" → "Upload assets" → перетягни всю папку сайту.
3. Deploy — сайт одразу отримає адресу `https://statut-site.pages.dev`.

Обидва варіанти повністю безкоштовні без обмежень по трафіку для такого сайту.

## Свій домен (наприклад statut-law.ua)

Хостинг залишиться безкоштовним, але сам домен купується окремо
(зазвичай $10–15/рік, або дешевше для .com.ua через українських реєстраторів
типу imena.ua). Після покупки домен прив'язується до GitHub Pages/Cloudflare
Pages у налаштуваннях DNS — інструкції є на сайтах цих сервісів.
